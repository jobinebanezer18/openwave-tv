# Contributing to OpenWave TV

Thanks for helping make public live TV easier to use.

1. Open an issue for a bug or improvement before a large change.
2. For playback bugs, include the channel name, country, browser and version, and the message shown in the app. If possible, include whether the channel works on the broadcaster's own site.
3. Run `npm ci`, `npm run build`, `go test ./...`, and `npm audit --audit-level=moderate` before a pull request.
4. Keep stream links in the upstream catalogs. Report dead links to the upstream project and do not add paid, encrypted, or unauthorized feeds here.
5. Keep the UI direct: the channel guide and video should remain the main focus. Support keyboard navigation and readable contrast.
